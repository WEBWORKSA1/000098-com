About 000098

Last updated October 27, 2026

000098.com takes its name from the hex color #000098, a deep ink blue. We started with one color and built outward: a reference page for every hex code, free tools that run entirely in your browser, and plain-English guides on color theory, accessibility and branding.

What we believe

  • Free and fast. Core tools stay free, need no account and work on any phone.
  • Accessible by default. Every color page shows WCAG contrast and color-blindness previews.
  • Accurate and transparent. Conversions use published formulas (sRGB, CIE Lab, OKLCH, Machado 2009). Where a value is an approximation, we say so.
  • Clear about money. We are funded by advertising, design services, sponsorships and supporters. Ads and sponsored placements are always labelled.

How we make money

We show ads through Google AdSense, offer paid design services, accept clearly labelled sponsorships and welcome donations. None of these influence the color data, which is computed automatically.

Corrections

Spotted an error? Use the contact form and we will fix it, usually within a few days.
